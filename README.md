24秋计算概论B大作业——麻将游戏（单机）version2
该款麻将游戏采用简单的规则：
1. 麻将一共有108张牌，分别为：条S，筒P，万M，1~9，每张牌四张
2. 玩家和三个电脑对决，玩家id为0，电脑玩家id为1、2、3
3. 麻将里，三个相同花色，数字大小连续递增的三张牌是“顺子”，三张相同的牌是“刻子”
4. 每局都是从玩家开始开始，分为摸牌，出牌，操作三个阶段
5. 玩家可以在自己的回合选择弃出自己手牌中的一张牌（包括刚摸到的）
6. 玩家可以“吃”上家的牌。（上家指玩家前面的人，本游戏中是id=3的电脑，“吃”指自己手中的两张牌和上家打出的牌能组成顺子，“吃”后三张牌放到副露，并且回合来到该玩家，该玩家打出一张牌）
7. 玩家可以“碰”任意玩家的牌（“碰”指自己手中的两张牌可以和其他玩家打出的牌形成刻子），碰后<u>需要摸牌</u>,然后打出一张牌
8. 玩家可以“杠”任意玩家的牌（“杠”是四张相同的牌，在副露里算一个刻子）（具体分为明杠、暗杠、补杠）
9. 明杠是自己手中的刻子可以和其他玩家打出的牌形成四张相同的牌，明杠之后回到摸牌阶段，摸一张打一张
10. 暗杠是自己回合内手中有四张一样的牌，杠后回到摸牌阶段，摸一张打一张
11. 补杠是玩家自己回合内手中有和副露里刻子一样的牌，补杠后玩家额外回合重新摸牌。（注：补杠打出的牌不能被碰、吃，只能用于胡牌判定，即其他玩家可以抢杠胡牌）
12. 胡牌判定：3*4+2，即四个面子（顺子和刻子都叫面子），和一个对子（将牌、雀头）比如\[M2 M2 M2 M3 M4 M5 S4 S5 S6 P2 P2 P2 P7 P7\]就是胡牌
13. 游戏结束：有一方胡牌或者牌堆发空，游戏结束。

欢迎大家来玩！
注：v2版本较为简陋，电脑玩家的智商较低（随即出牌拼的就是运气，玩的就是无脑的赌博），并且游戏界面比较简陋，需要用户自己在python环境中运行。
